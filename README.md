# Bubble Star Dash

Bubble Star Dash is a very light Expo React Native prototype for a child-friendly survivor-style mobile game.

## Play locally

1. From `/Users/gui.teles/Documents/New project`, run `npm install` if dependencies are missing.
2. Start the app with `npm start`.
3. Use Expo Go, an iOS simulator, an Android emulator, or run the web target with `npm run web`.

## Current prototype

- Portrait-first mobile layout
- One-finger movement
- Automatic bubble shots
- Word-category rounds inspired by simple word puzzle games
- Header game-type picker with Mix, colors, fruit, shapes, toys, and objects
- Matching puffs for colors, fruit, shapes, toys, and everyday objects
- 30 quick levels with rising word goals and shorter timers
- One-tap next-level loop with three-star rewards
- Soft puff enemies
- Star collectibles with a gentle magnet pull
- Three-heart friendly fail state
- One-minute rounds with instant replay

This is intentionally small and dependency-light so the next iteration can focus on feel, art, sound, and simple progression.
